!Bugs & Root Causes
BUG #1 — Duct Material: Fixed vs Physics-based Weight Constant

The Excel workbook uses a fixed constant of 1.2497 lbs/ft² for all rectangular duct regardless of gauge or size. The web app calculates weight from SMACNA physics (gauge thickness × steel density), which correctly produces lower weights for thin 26-gauge small duct and higher weights for thick 20-gauge large duct.


For small ducts (≤12", gauge 26): Excel density ≈ 1.25 lbs/ft² vs web ≈ 0.91 lbs/ft² → 27% weight gap → ~22% material cost gap
For large ducts (18-20", gauge 24): Excel density ≈ 1.25 lbs/ft² vs web ≈ 1.15 lbs/ft² → ~8% weight gap → ~6% material cost gap

Fix: Replace the physics weight formula with the same constant used in Excel: const SHEET_METAL_LBS_PER_SQFT = 1.2497; then weight = surfaceArea × SHEET_METAL_LBS_PER_SQFT. This matches the Excel's constant AC5 = 0.567 kg/ft².
BUG #2 — Louvers & Dampers: Type Not Mapped + Size Category Missing

The Excel uses a size category system (Small / Large / Enormous) with fixed labor hours per category and per type. The web app uses a face-area formula with types like 'OA Louver'. When 'Standard Aluminum' is passed, it falls back to the OA Louver area formula, producing $23.50 labor vs Excel's $350 — a 93% error.


Excel install table: Standard Aluminum → Large=12 hrs, Enormous=14 hrs (×$25/hr). Web app returns 0.93 hrs × $25 = $23.50.

Fix: Add 'Standard Aluminum' and 'Hurricane' to LOUVER_DAMPER_PRICING. Add a size-category field to each row (Small/Large/Enormous) with a fixed hours table matching the Excel install table, replacing the face-area formula for catalog types.
BUG #3 — Fan & Louver Misc Rate: 3% vs 20%

The Excel Fan Schedule and Louvers & FD sheet apply a 20% miscellaneous parts rate to the unit price (e.g. fan unit=$2,500 → misc=$500). The web app applies only 3% (the MISC_CONSUMABLES_PCT), and applies it to accMaterial (accessories) — not the equipment cost. When there are no accessories, misc becomes $0.


Fan EF-1: Excel misc=$500 (20% of $2,500). Web misc=$0.
Louver L-1: Excel misc=$400 (20% of $2,000). Web misc=$60 (3% of mat).

Fix: Add a miscPartsUpliftPct field defaulting to 0.20 for fans and louvers. Apply it to equipCost: misc = equipCost × 0.20. The 3% misc on accessories can remain as a separate line.
BUG #4 — Fan Labor: CFM-based Hours vs Size-Category Hours

The Excel Fan Schedule categorizes fans as Small/Large/Enormous and applies fixed labor hours per category. EF-1 is "Enormous Inline Exhaust" → 14 hrs × $25 = $350. The web app looks up hours by CFM: 950 CFM → 5.5 + 1.5 = 7 hrs → $175 (50% too low).


Excel install hours by size: Inline Exhaust: Small=9, Large=11, Enormous=14 hrs. The "Enormous" fan EF-1 at 950 CFM would never hit the 14-hr category via CFM lookup.

Fix: Add a sizeCategory field (Small/Large/Enormous) to each fan row. Build a FAN_LABOR_HOURS_BY_TYPE_AND_SIZE table matching the Excel sheet. Use it when sizeCategory is set; fall back to CFM table otherwise.
BUG #5 — Fan Schedule: Wall/Roof Penetration Not Added to Material

The Excel adds a penetration line item to material: $200 per wall penetration, $100 per roof. The web app's calcFanUnit() does not accept or add a penetration cost to the material total. All 6 fans in the test are missing $200 each from material.

Fix: Add penetrationCost field to fan rows. Add penetrationType (wall=$200, roof=$100). Include in totalMaterial calculation.
BUG #6 — Packaged Unit: Misc Applied to Wrong Base

The Excel applies a ~2.5% misc rate to the total equipment cost on the Unit Schedule. With $567,500 in equipment and no accessories, Excel misc = $14,187.50. The web app's MISC_CONSUMABLES_PCT = 0.03 is applied to accMaterial (accessories), which is $0 when no accessories are selected → misc = $0. The $14,187.50 is completely missing from the bid.

Fix: Apply miscPct to equipCost + accMaterial (or at minimum to equipCost). The exact rate in Excel appears to be 2.5% for packaged units. Expose this as a configurable field defaulting to 2.5%.
